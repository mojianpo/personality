# 人格罗盘

六维人格倾向测验，支持桌面与手机浏览器。36 道题，每题 5 档回答；结果为 4 个经典维度加 2 个补充维度，共 64 种组合。`/types` 提供按四个系列浏览的 64 种人格类型图鉴，结果页可跳转到对应类型。结果用于自我探索，不作心理诊断。

## 运行

需要 Python 3.10+，无第三方依赖。运行 `python server.py`，打开 http://127.0.0.1:8000 。可通过 `PORT` 和 `DB_PATH` 环境变量指定端口与数据库文件。默认数据库位于 `data/personality.db`。

## 测试

运行 `python -m unittest discover -s tests -v`。

统计口径：页面展示人数为 1000 加上 SQLite 中的真实独立完成人数。匿名浏览器 ID 首次完成完整测验时计为 1 人；同一浏览器重测会保存新记录，但人数不重复增加。清除浏览器存储或换设备会被视为新人。服务端不收集姓名、邮箱或 IP。此测验为原创自我探索题目，不是参考网站的题库或临床量表。

16 张人格插画来自用户提供的 PersonalityKey 静态资源地址，已保存为项目内 WebP 文件，供图鉴和结果页使用。该站未在资源页提供明确的复用许可证；公开部署前需确认图片使用权限。
